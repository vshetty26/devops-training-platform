## 🚀 How to Use

### Prerequisites:
- Docker Desktop installed and running
- Node.js 20+
- Python 3.11+

### Start the Platform:

```bash
# 1. Fix Docker PATH (one-time setup)
export PATH="/Applications/Docker.app/Contents/Resources/bin:$PATH"

# 2. Start backend
cd ~/Desktop/Devops__Arena
./start-backend.sh

# 3. Start frontend (new terminal)
cd ~/Desktop/Devops__Arena  
./start-frontend.sh

# 4. Open browser
open http://localhost:5173

# 5. Login
# Username: demo
# Password: demo123
```
