# Deployment Guide

## Frontend - Vercel
1. Go to https://vercel.com/new
2. Import GitHub repo: vshetty26/devops-training-platform
3. Root Directory: frontend
4. Environment: VITE_API_URL=https://your-backend.railway.app
5. Deploy

## Backend - Railway  
1. Go to https://railway.app/new
2. Import from GitHub
3. Root Directory: backend
4. Deploy
